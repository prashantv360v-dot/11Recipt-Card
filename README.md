# 🍝 Responsive Recipe Card

A beautifully designed and fully responsive recipe card webpage built using **HTML5 and CSS3**. It displays a delicious recipe with a food image, ingredients list, cooking information, and step-by-step preparation instructions.

## ✨ Features

- 🍽️ Beautiful and modern recipe card design
- 🖼️ Food image with a recipe badge
- 🥗 Complete ingredients list
- 📝 Numbered preparation steps
- ⏱️ Preparation time and cooking time
- 👥 Serving information
- 📱 Fully responsive design for mobile, tablet, and desktop
- 🎨 Clean layout with attractive colors and rounded corners
- 💻 Simple and beginner-friendly code
- 🚫 No JavaScript required

## 🛠️ Technologies Used

- **HTML5** — For webpage structure and recipe content
- **CSS3** — For styling, layout, and responsive design
- **CSS Media Queries** — For mobile and tablet responsiveness
- **Unsplash** — For the food image

## 🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the repository:

   ```bash
   https://github.com/prashantv360v-dot
   ```

2. Open the project folder:

   ```bash
   cd 11recipe-card
   ```

3. Open `index.html` in your web browser.

You can also open the project directly in Visual Studio Code and use the Live Server extension.

## 📱 Responsive Design

The webpage adapts to different screen sizes:

- **Desktop:** Ingredients and preparation steps appear side by side.
- **Tablet:** The layout adjusts to provide comfortable spacing.
- **Mobile:** Sections stack vertically for easy reading.

## 🍴 Recipe Details

**Recipe:** Creamy Garlic Pasta

- Preparation time: 10 minutes
- Cooking time: 20 minutes
- Servings: 2 people

### Ingredients

- 200 g pasta
- 2 tablespoons olive oil
- 4 garlic cloves
- 1 cup fresh cream
- ½ cup grated Parmesan cheese
- Salt and black pepper
- Fresh parsley

It is suitable for beginners who want to build their frontend development portfolio.
